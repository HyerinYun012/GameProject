# CrowGame UI·캐릭터 프로토타입

맵 없이 캐릭터 조작과 인벤토리 계통만 검수하는 Pico2D 프로토타입입니다.

## 실행

`RunCrowGame.cmd`를 더블클릭하거나 프로젝트 루트에서 다음 명령을 실행합니다.

```powershell
python CrowGame/main.py
```

## 조작

- `WASD`: 걷기
- `Shift + WASD`: 달리기
- `Tab`: 15칸 인벤토리 열기/닫기
- 마우스 왼쪽 드래그: 인벤토리·핫바·도구·방어구 슬롯 간 이동
- `E` 또는 `Space`: 현재 `tool` 슬롯의 도구 사용
  - 도끼: 도끼질
  - 곡괭이: 채광
  - 낚싯대: 낚시
  - 검·창: 공격
- `H`: 피격 애니메이션 확인
- `K`: 쓰러지기/죽음 애니메이션 확인
- `R`: 쓰러진 캐릭터 일으키기
- `C`: 맵이 없는 동안 자동 수집 기능을 시험하기 위한 재료 수집
- `Esc`: 종료

## 동작 규칙

- 인벤토리는 5×3, 총 15칸입니다.
- 핫바는 별도 저장소가 아니라 인벤토리 첫 줄 5칸을 그대로 보여주므로 항상 동기화됩니다.
- `tool`에는 나무/돌 검, 낚싯대, 횃불, 나무/돌 곡괭이, 나무/돌 도끼, 나무/돌 창만 들어갑니다.
- `tool`에 장착한 도구는 캐릭터 옆에도 즉시 표시되며, `E`/`Space`를 누르면 해당 도구 애니메이션이 실행됩니다.
- `armor`에는 간이 갑옷만 들어가며 장착 시 방어력이 4 증가합니다.
- 잘못된 종류의 아이템을 장착 슬롯에 놓으면 원래 위치로 돌아갑니다.
- 이번 단계에서는 지도와 충돌체를 불러오지 않습니다.
- 이동키를 놓으면 마지막 이동 방향을 바라보는 대기 자세를 유지합니다.
- 도끼질·채광질·낚시·검/창 공격은 앞, 뒤, 오른쪽, 왼쪽 네 방향을 지원합니다.

전체 구현 기준과 완료 조건은 [PRD.md](PRD.md)를 참고하세요.
