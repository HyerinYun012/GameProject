# CrowGame 4개 맵·인벤토리 프로토타입

폐허 마을에서 시작해 까마귀 숲, 늑대 숲, 곰 숲을 양방향으로 이동하는 Pico2D 프로토타입입니다. 기존 캐릭터 이동·행동과 인벤토리, 핫바, 도구, 방어구 UI를 맵 위에 그대로 유지합니다.

## 실행

`RunCrowGame.cmd`를 더블클릭하거나 프로젝트 루트에서 다음 명령을 실행합니다.

```powershell
python CrowGame/main.py
```

## 조작

- `WASD`: 걷기
- `Shift + WASD`: 달리기
- `Tab`: 15칸 인벤토리 열기/닫기
- `C`: 제작 카드 UI 열기/닫기
- 제작 카드 마우스 클릭: 재료와 인벤토리 공간이 충분하면 아이템 제작
- 마우스 왼쪽 드래그: 인벤토리·핫바·도구·방어구 슬롯 간 이동
- 아이템을 슬롯 밖 월드로 드래그: 현재 맵에 아이템 버리기
- `E`: 가까운 JSON 리소스 채집 또는 이벤트 상호작용
- `Space`: 현재 `tool` 슬롯의 도구 사용
  - 도끼: 도끼질
  - 곡괭이: 채광
  - 낚싯대: 낚시
  - 검·창: 공격
- `H`: 피격 및 HP 감소 확인
- `K`: HP를 모두 소진해 쓰러지기 확인
- `R`: 쓰러진 캐릭터를 최대 HP로 일으키기
- `Esc`: 종료

## 동작 규칙

- 인벤토리는 5×3, 총 15칸입니다.
- 새 게임 인벤토리에는 도구 10개만 들어 있고 나머지 5칸은 비어 있습니다.
- 핫바는 별도 저장소가 아니라 인벤토리 첫 줄 5칸을 그대로 보여주므로 항상 동기화됩니다.
- `C` 제작 UI에는 13개 완성품이 이미지·이름·재료 순서의 카드로 표시됩니다.
- 재료 표기는 `필요 수량/보유 수량` 순서이며 충분하면 초록색, 부족하면 빨간색입니다.
- 제작 카드를 클릭하면 재료를 차감하고 완성품을 인벤토리에 추가합니다. 공간이 없거나 재료가 부족하면 아무 재료도 잃지 않습니다.
- `tool`에는 나무/돌 검, 낚싯대, 횃불, 나무/돌 곡괭이, 나무/돌 도끼, 나무/돌 창만 들어갑니다.
- `tool`에 장착한 도구는 캐릭터 옆에도 즉시 표시되며, `Space`를 누르면 해당 도구 애니메이션이 실행됩니다.
- `armor`에는 간이 갑옷만 들어가며 장착 시 방어력이 4 증가합니다.
- 잘못된 종류의 아이템을 장착 슬롯에 놓으면 원래 위치로 돌아갑니다.
- 아이템을 모든 슬롯 밖으로 드래그하면 인벤토리에서 빠지고 플레이어 주변의 통과 가능한 임의 위치에 76픽셀 크기의 큰 아이콘과 수량이 표시됩니다.
- 버린 아이템은 맵별로 유지됩니다. 투척 후 캐릭터가 30픽셀 이상 움직이고 아이템의 115픽셀 획득 범위에 들어가면 빈 슬롯/기존 스택에 자동으로 추가됩니다.
- 채집 보상이 인벤토리 부족으로 바닥에 떨어진 경우에도 가까이 가면 자동 획득하며, 공간이 부족하면 남은 수량은 월드에 유지됩니다.
- `ruined_town_demo.json` → `crow_map.json` → `wolf_map.json` → `bear_map.json` 순서로 진행하며 인접 맵끼리 양방향 이동할 수 있습니다.
- 각 JSON의 보이는 타일 레이어를 TSX/GID 기준으로 직접 그리며 `collision`, `spawn`, `transitions`, `Resources`, `Events` 레이어도 함께 사용합니다.
- `ruined_town_demo.json`의 `Ground`, `Walls`, `Props`와 `crow_map.json`의 `ground`, `plants*` 수정 사항이 정적 배경 PNG 없이 반영됩니다.
- 폐허 마을의 `Walls` 타일과 자동차·가구·상자·장벽·펜스·나무 등의 고형 `Props`에는 충돌이 적용되며 바닥 장식과 도로는 통과할 수 있습니다.
- 폐허 마을 타일셋은 `assets/ruined_town`에 포함되어 다른 PC에서도 `Downloads` 폴더 없이 로드됩니다.
- 실행 중 수정한 JSON은 해당 맵에 다시 진입할 때 파일 변경을 감지해 다시 로드합니다.
- 카메라는 모든 맵에서 0.50배 줌으로 더 넓은 범위를 보여주며 캐릭터를 따라갑니다.
- 나무는 도끼, 돌은 곡괭이를 `tool` 슬롯에 장착한 상태에서만 `E`로 채집할 수 있습니다.
- 풀과 꽃은 도구 없이 `E`로 채집하며, 채집이 끝난 일반 리소스는 월드에서 사라집니다.
- 사과나무는 `E`로 수확하면 `assets/apple.png` 아이콘의 사과 3개를 지급합니다. 나무는 남아 있고 완료 표시와 남은 시간이 보이며 30초 뒤 다시 수확할 수 있습니다.
- 이벤트는 `E`로 실행하며 `after_sprite`가 있으면 이미지가 바뀌고, 없으면 완료 후 사라집니다.
- 곰 숲의 엔딩 통로에 들어가면 안내 후 게임이 종료됩니다.
- 이동키를 놓으면 마지막 이동 방향을 바라보는 대기 자세를 유지합니다.
- 도끼질·채광질·낚시·검/창 공격은 앞, 뒤, 오른쪽, 왼쪽 네 방향을 지원합니다.
- 좌측 상단에는 숫자 없이 HP와 SP의 남은 비율을 보여주는 색칠된 막대가 표시됩니다.
- HP와 SP의 최대치는 100입니다. 적의 공격을 받으면 HP가 감소하고 0이 되면 쓰러집니다.
- `Shift` 달리기는 SP를 초당 25 소모합니다. SP가 0이면 걷기만 가능하고, 걷거나 멈추면 초당 18씩 회복됩니다.

전체 구현 기준과 완료 조건은 [PRD.md](PRD.md)를 참고하세요.
