# CrowGame 4개 맵·인벤토리 프로토타입

폐허 마을에서 시작해 까마귀의 숲, 늑대 협곡, 곰의 산을 양방향으로 이동하는 Pico2D 프로토타입입니다. `sprite-preview/dist/assets`의 v26 모험가 캐릭터와 인벤토리, 핫바, 도구, 방어구 UI를 맵 위에 표시합니다.

## 실행

`RunCrowGame.cmd`를 더블클릭하거나 프로젝트 루트에서 다음 명령을 실행합니다.

```powershell
python CrowGame/main.py
```

## 조작

- `WASD`: 걷기
- `Shift + WASD`: 달리기
- `Tab`: 15칸 인벤토리 열기/닫기
- `C`: 제작 카드 UI 열기/닫기
- 마우스 이동: 툴바의 창·돌 투척 방향 조준
- 마우스 왼쪽 클릭: 검·맨손 근접 공격 또는 조준점으로 창·돌 투척
- 제작 카드 마우스 클릭: 재료와 인벤토리 공간이 충분하면 아이템 제작
- 마우스 왼쪽 드래그: 인벤토리·핫바·툴바·방어구 슬롯 간 이동
- 아이템을 슬롯 밖 월드로 드래그: 현재 맵에 아이템 버리기
- `E`: 가까운 리소스·이벤트 상호작용, 장착 도구 행동·검 공격, 간이 침구·모닥불 설치 또는 회수, 툴바 사과 먹기
- `H`: 피격 및 HP 감소 확인
- `K`: HP를 모두 소진해 쓰러지기 확인
- 게임 오버 UI의 `다시 하기`: 인벤토리·맵 진행·동물·호감도 등 모든 상태를 초기화하고 새 게임 시작
- 게임 오버 UI의 `종료`: 게임 종료
- `Esc`: 종료

## 동작 규칙

- 인벤토리는 5×3, 총 15칸입니다.
- 새 게임 인벤토리에는 도구 10개만 들어 있고 나머지 5칸은 비어 있습니다.
- 사과·나뭇가지·돌·섬유는 한 슬롯에 최대 10개만 쌓이며 초과 수량은 다음 슬롯에 보관됩니다.
- 핫바는 별도 저장소가 아니라 인벤토리 첫 줄 5칸을 그대로 보여주므로 항상 동기화됩니다.
- `C` 제작 UI에는 13개 완성품이 이미지·이름·재료 순서의 카드로 표시됩니다.
- 재료 표기는 `필요 수량/보유 수량` 순서이며 충분하면 초록색, 부족하면 빨간색입니다.
- 제작 카드를 클릭하면 재료를 차감하고 완성품을 인벤토리에 추가합니다. 공간이 없거나 재료가 부족하면 아무 재료도 잃지 않습니다.
- 도구와 간이 갑옷은 개별 내구도를 가지며, 슬롯 안의 색상 게이지와 마우스 오버 `현재/최대` 툴팁으로 확인할 수 있습니다. 제작품은 최대 내구도로 생성되고 월드에 버렸다가 주워도 현재 내구도가 유지됩니다.
- `TOOL BAR`에는 도구, 방어구, 재료, 음식, 제작품을 포함한 모든 아이템을 넣을 수 있습니다.
- 툴바에 넣은 아이템은 종류와 관계없이 캐릭터 손에 표시됩니다. 장착 도구와 검 공격은 `E`로 실행하며, 검·맨손 공격과 창·돌 투척은 좌클릭으로도 실행합니다.
- 플레이어는 대기·걷기·달리기·피격·사망에 v26 시트의 8방향 전용 프레임을 사용합니다. 도끼·곡괭이·낚싯대·검·창 행동은 같은 화풍의 방향별 대기 몸체와 실제 장착 아이콘의 4단계 궤적을 합성합니다.
- 돌도끼를 툴바에 장착하면 대기·걷기·달리기 중에도 전용 픽셀 도끼가 8방향 손 위치와 보폭에 맞춰 함께 움직입니다.
- 나무 창, 돌 창, 돌을 툴바에 넣으면 마우스로 조준할 수 있습니다. 좌클릭하면 캐릭터의 공격 동작과 함께 포물선 투사체가 날아갑니다.
- 나무 창은 15, 돌 창은 30, 돌은 18의 피해를 주며 캐릭터 반경 5타일 안의 실제 비행 경로가 AI와 겹쳤을 때만 명중합니다.
- 나무 검은 10, 돌 검은 20의 피해와 전방 1.2타일 사거리를 가집니다. 툴바가 비었으면 좌클릭으로 피해 5·전방 1타일의 맨손 공격을 합니다.
- 살아 있는 까마귀·늑대·곰은 피해 여부와 관계없이 개체 위에 HP 게이지를 항상 표시합니다. 의심·수색은 노란색 `?` 전용 이미지로, 경보·확신은 붉은색 `!` 전용 이미지로 HP 게이지와 간격을 두고 크게 표시합니다. HP가 0이면 사망 애니메이션 마지막 프레임에 머뭅니다.
- 까마귀는 대기 8fps·비행/급강하 14fps·피격 12fps·사망 10fps와 8방향 스프라이트를 사용합니다. 상하 움직임은 연속 시간 곡선으로 계산하고 앞선 타원 궤도 목표를 추적해 멈춤·재출발 떨림 없이 비행합니다.
- `Events` 오브젝트를 최초 완료하면 `reward`가 현재 숲의 종 호감도에 누적되며 각 종의 최대치는 100입니다. 발전기 보상도 최초 1회만 적용됩니다.
- 까마귀 호감도가 100 미만이면 늑대 협곡과 곰의 산에도 까마귀가 출현하고, 늑대 호감도가 100 미만이면 곰의 산에도 늑대가 출현합니다. 각 호감도 100에서는 해당 종이 후속 맵에 출현하지 않습니다.
- 0~79의 동물은 발견 확정 후 선제 공격할 수 있습니다. 80~99는 `?`/`!` 관찰·경보·수색은 유지하지만 먼저 공격하지 않으며, 플레이어가 먼저 타격해 도발한 경우에만 반격합니다. 100 화해 상태에서는 감지·추격·공격하지 않습니다.
- 까마귀는 전방 7타일·110도 시야와 10타일 경보를 사용해 늑대·곰에게 마지막 위치를 전달합니다. 늑대는 6타일·120도 시야와 직접 발견 울음 경보를 사용합니다.
- 놓친 동물은 까마귀 2타일, 늑대 3타일, 곰 2타일 반경에서 마지막 위치를 수색합니다. 감지 범위 원뿔은 표시하지 않습니다.
- 공격력은 까마귀 20, 늑대 40, 곰 55이며 이동속도는 까마귀 5, 늑대 4, 곰 3.2입니다. 인간은 걷기 3, 달리기 4.5이므로 늑대에게서 달려 도망칠 수 있지만 SP가 소모됩니다.
- 곰은 평소 서식지에 머물고 주로 경보를 받거나 가까운 정면에서 인간을 발견했을 때 움직입니다. 까마귀는 경보가 주 행동이며 3.5초 간격으로 하강·쪼기 공격을 할 수 있습니다.
- AI를 창·돌·검·맨손으로 명중시키면 해당 종 호감도가 5 감소하고 공격 위치를 확정한 AI가 반격합니다.
- 좌측 상단 HP/SP 아래에서 까마귀·늑대·곰 초상과 호감도 게이지를 항상 확인할 수 있습니다.
- 던진 창·돌은 명중 또는 착탄 위치에 남기 때문에 이동 후 다시 접근해 회수할 수 있습니다. 창은 착탄할 때마다 내구도 3을 잃고, 0이면 파괴되어 남지 않습니다. 창은 좌클릭 투척 전용이며 근접 피해를 주지 않습니다.
- 간이 침구와 모닥불은 툴바에 넣고 `E`를 누르면 주변의 통과 가능한 위치에 설치됩니다. 설치물 가까이에서 `E`를 누르면 인벤토리로 회수됩니다.
- 설치물은 맵별로 유지되며 인벤토리에 공간이 없으면 회수되지 않고 월드에 남습니다.
- `armor`에는 간이 갑옷만 들어갑니다. 갑옷은 적의 공격 1회당 내구도 2를 잃는 대신 그 공격의 HP 피해를 전부 막으며, 내구도를 0으로 만든 공격까지 막은 뒤 파괴됩니다.
- 방어구가 아닌 아이템을 `ARMOR` 슬롯에 놓으면 원래 위치로 돌아갑니다.
- 아이템을 모든 슬롯 밖으로 드래그하면 인벤토리에서 빠지고 플레이어 주변의 통과 가능한 임의 위치에 76픽셀 크기의 큰 아이콘과 수량이 표시됩니다.
- 버린 아이템은 맵별로 유지됩니다. 투척 후 캐릭터가 30픽셀 이상 움직이고 아이템의 115픽셀 획득 범위에 들어가면 빈 슬롯/기존 스택에 자동으로 추가됩니다.
- 채집 보상이 인벤토리 부족으로 바닥에 떨어진 경우에도 가까이 가면 자동 획득하며, 공간이 부족하면 남은 수량은 월드에 유지됩니다.
- `ruined_town_demo.json` → `crow_map.json` → `wolf_map.json` → `bear_map.json` 순서로 진행하며 인접 맵끼리 양방향 이동할 수 있습니다.
- 각 JSON의 보이는 타일 레이어를 TSX/GID 기준으로 직접 그리며 `collision`, `spawn`, `transitions`, `Resources`, `Events` 레이어도 함께 사용합니다.
- `ruined_town_demo.json`의 `Ground`, `Walls`, `Props`와 `crow_map.json`의 `ground`, `plants*` 수정 사항이 정적 배경 PNG 없이 반영됩니다.
- 폐허 마을의 `Walls` 타일과 자동차·가구·상자·장벽·펜스·나무 등의 고형 `Props`에는 충돌이 적용되며 바닥 장식과 도로는 통과할 수 있습니다.
- 폐허 마을 타일셋은 `assets/ruined_town`에 포함되어 다른 PC에서도 `Downloads` 폴더 없이 로드됩니다.
- 실행 중 수정한 JSON은 해당 맵에 다시 진입할 때 파일 변경을 감지해 다시 로드합니다.
- 카메라는 모든 맵에서 0.50배 줌으로 더 넓은 범위를 보여주며 캐릭터를 따라갑니다.
- 나무는 도끼, 돌은 곡괭이를 툴바에 넣은 상태에서만 `E`로 채집할 수 있습니다.
- 검은 AI 적중 시 4, 도끼는 나무 타격 시 4, 곡괭이는 돌 타격 시 4의 내구도를 잃습니다. 빗나간 검 공격이나 잘못된 채집 도구는 내구도를 소모하지 않습니다.
- 최대 내구도는 나무 검 40, 돌 검 80, 나무 곡괭이 24, 돌 곡괭이 60, 낚싯대 30, 나무 창 12, 돌 창 21, 나무 도끼 24, 돌 도끼 60, 간이 갑옷 20입니다.
- 낚싯대 내구도 2 감소는 추후 입질 성공으로 낚시 미니게임을 시작하는 시점에 적용하며, 현재는 미니게임이나 임의 감소를 추가하지 않습니다.
- 풀과 꽃은 도구 없이 `E`로 채집하며, 채집이 끝난 일반 리소스는 월드에서 사라집니다.
- 사과나무는 `E`로 수확하면 `assets/apple.png` 아이콘의 사과 3개를 지급합니다. 수확 직후 빨간 열매가 초록색으로 바뀌고 30초 뒤 다시 빨간색으로 돌아오며, 나무 위의 `OK 30s` 텍스트는 표시하지 않습니다.
- 사과를 툴바에 넣고 `E`를 누르면 1개를 먹고 HP를 최대 5 회복합니다. HP는 최대 100을 넘지 않으며 쓰러진 상태에서는 먹지 않습니다.
- 생선과 익힌 생선은 아직 구현하지 않습니다. 향후 낚시·조리 시스템 추가 시 각각 HP 5와 HP 10을 회복하도록 명세만 예약했습니다.
- 이벤트는 `E`로 실행하며 `after_sprite`가 있으면 이미지가 바뀌고, 없으면 완료 후 사라집니다.
- 곰의 산 엔딩 통로에서는 최종 종 호감도에 따라 `완전한 화해`, `공존`, `불안한 휴전`, `대립` 엔딩 중 하나가 표시됩니다.
- 이동키를 놓으면 마지막 이동 방향을 바라보는 대기 자세를 유지합니다.
- 도끼질·채광질·낚시·검/창 공격은 8방향 모두 새 캐릭터 몸체와 장착 아이콘을 합성하는 동일한 방식으로 재생됩니다.
- 좌측 상단에는 숫자 없이 HP와 SP의 남은 비율을 보여주는 색칠된 막대가 표시됩니다.
- HP와 SP의 최대치는 100입니다. 적의 공격을 받으면 HP가 감소하고 0이 되면 쓰러지며, 게임 오버 UI에서 완전 초기화 후 다시 하거나 게임을 종료할 수 있습니다.
- `Shift` 달리기는 SP를 초당 25 소모합니다. SP가 0이면 걷기만 가능하고, 걷거나 멈추면 초당 18씩 회복됩니다.

전체 구현 기준과 완료 조건은 [PRD.md](PRD.md)를 참고하세요.

```powershell
python -m py_compile CrowGame/main.py CrowGame/game_model.py CrowGame/map_system.py
```
