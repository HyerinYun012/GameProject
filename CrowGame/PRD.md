# CrowGame 프로토타입 PRD

- 문서 상태: 구현 기준선
- 최종 갱신: 2026-11-14
- 대상 빌드: 맵이 없는 캐릭터·인벤토리·장비 검수 프로토타입

## 1. 목표

플레이어 캐릭터의 이동 및 행동 애니메이션과 15칸 인벤토리, 핫바, 도구, 방어구 장착 흐름을 맵 없이 검수할 수 있는 실행 가능한 프로토타입을 만든다.

현재 단계의 핵심은 다음과 같다.

1. 마지막 이동 방향이 캐릭터의 대기 방향으로 유지되어야 한다.
2. 도구 슬롯에 장착한 도구가 캐릭터에게 즉시 시각적으로 반영되어야 한다.
3. 앞, 뒤, 오른쪽, 왼쪽 네 방향에서 장착 도구의 행동이 올바른 방향으로 재생되어야 한다.
4. 인벤토리 첫 줄과 핫바가 동일한 데이터를 공유해야 한다.

## 2. 현재 범위

### 포함

- 남성 모험가 캐릭터
- 걷기와 달리기
- 네 방향 대기 자세 유지
- 피격과 쓰러짐
- 검·창 공격
- 도끼질, 채광질, 낚시
- 15칸 인벤토리
- 5칸 핫바
- 도구 및 방어구 장착
- 수집 아이템의 인벤토리 자동 추가 시험

### 제외

- 실제 월드 맵과 카메라
- 지형 및 오브젝트 충돌
- 나무, 광맥, 낚시터 등 월드 대상 판정
- 전투 대상과 실제 피해 계산
- 저장 및 불러오기
- 제작, 상점, 퀘스트

따라서 현재 `E` 또는 `Space`는 월드 오브젝트와 상호작용하는 키가 아니라 장착된 도구의 애니메이션을 직접 검수하는 키다.

## 3. 조작

| 입력 | 동작 |
|---|---|
| `W` | 위로 이동, 키를 놓으면 뒤를 본 대기 자세 유지 |
| `S` | 아래로 이동, 키를 놓으면 앞을 본 대기 자세 유지 |
| `A` | 왼쪽 이동, 키를 놓으면 왼쪽을 본 대기 자세 유지 |
| `D` | 오른쪽 이동, 키를 놓으면 오른쪽을 본 대기 자세 유지 |
| `Shift + WASD` | 달리기 |
| `Tab` | 인벤토리 열기·닫기 |
| 마우스 왼쪽 드래그 | 인벤토리·핫바·장비 슬롯 간 아이템 이동 |
| `E` 또는 `Space` | 현재 도구 슬롯에 장착한 도구 사용 |
| `H` | 피격 애니메이션 검수 |
| `K` | 쓰러짐 애니메이션 검수 |
| `R` | 쓰러진 캐릭터 일으키기 |
| `C` | 자동 수집 시험용 재료 1개 획득 |
| `Esc` | 게임 종료 |

## 4. 방향 및 애니메이션 규칙

### 방향 상태

- 방향은 `up`, `down`, `left`, `right` 네 가지다.
- 이동키를 누르면 해당 방향으로 갱신한다.
- 이동키를 놓아 `idle` 상태가 되어도 마지막 방향을 변경하지 않는다.
- 행동이 종료된 뒤에도 행동을 시작한 방향을 유지한다.
- 좌우 대기 프레임은 원본 아틀라스의 실제 얼굴 방향과 일치해야 한다.

### 이동 프레임

- 좌우 이동은 각 9프레임을 사용한다.
- 앞뒤 이동은 반대 방향 프레임이 섞이지 않도록 각 5프레임만 사용한다.
- 달리기는 걷기와 동일한 프레임을 더 높은 FPS로 재생한다.

### 도구 행동 방향표

| 도구 종류 | 앞 `down` | 뒤 `up` | 오른쪽 `right` | 왼쪽 `left` |
|---|---|---|---|---|
| 나무·돌 도끼 | 정면 몸동작 + 도끼 궤적 | 후면 몸동작 + 캐릭터 뒤 도끼 궤적 | 원본 우측 도끼질 | 우측 도끼질 좌우 반전 |
| 나무·돌 곡괭이 | 정면 몸동작 + 곡괭이 궤적 | 후면 몸동작 + 캐릭터 뒤 곡괭이 궤적 | 원본 우측 채광질 | 우측 채광질 좌우 반전 |
| 낚싯대 | 정면 몸동작 + 낚싯대 궤적 | 후면 몸동작 + 캐릭터 뒤 낚싯대 궤적 | 원본 우측 낚시 | 원본 좌측 낚시 |
| 나무·돌 검 | 원본 정면 공격 | 원본 후면 공격 | 원본 우측 공격 | 원본 좌측 공격 |
| 나무·돌 창 | 원본 정면 공격 | 원본 후면 공격 | 원본 우측 공격 | 원본 좌측 공격 |
| 횃불 | 방향별 장착 표시 | 방향별 장착 표시 | 방향별 장착 표시 | 방향별 장착 표시 |

원본 시트에 도끼·곡괭이·낚싯대의 앞뒤 전용 완성 프레임이 없으므로 앞뒤 행동은 방향에 맞는 정면·후면 몸 프레임과 장착 아이콘의 궤적을 합성한다. 뒤 방향에서는 도구를 캐릭터보다 먼저 그려 몸 뒤에 위치하도록 한다.

## 5. 캐릭터 외형

- 기본 외형은 남성 숲 모험가다.
- 올리브색 긴소매 튜닉, 가죽 벨트와 장갑, 짙은 바지와 부츠를 착용한다.
- 모든 상태에서 얼굴, 체형, 색상 및 픽셀 화풍을 통일한다.
- 대기, 걷기, 달리기, 피격, 쓰러짐 및 도구 행동에서 의상이 유지되어야 한다.

## 6. 인벤토리와 장비

### 인벤토리

- 5열 × 3행, 총 15칸이다.
- 수집된 아이템은 기존 스택을 먼저 채우고, 남으면 앞쪽 빈 슬롯부터 들어간다.
- 빈 공간이 없으면 아이템을 잃지 않고 획득 실패를 표시한다.

### 핫바

- 화면 하단 중앙에 항상 표시한다.
- 인벤토리 0~4번 슬롯을 그대로 보여준다.
- 별도 복사본을 만들지 않으며 인벤토리 첫 줄과 항상 동기화한다.

### 도구 슬롯

- 화면 우측 하단에 항상 표시한다.
- 검, 창, 도끼, 곡괭이, 낚싯대, 횃불만 넣을 수 있다.
- 장착 직후 캐릭터 옆에 해당 도구를 표시한다.
- 도구를 빼거나 교체하면 캐릭터 표시와 행동도 즉시 갱신한다.

### 방어구 슬롯

- 도구 슬롯 옆에 항상 표시한다.
- 간이 갑옷만 넣을 수 있다.
- 현재 간이 갑옷 장착 시 방어력은 4 증가한다.

## 7. UI 배치

- 핫바: 화면 하단 중앙
- 도구 슬롯: 화면 우측 하단
- 방어구 슬롯: 도구 슬롯 오른쪽
- 인벤토리: `Tab`을 누른 동안 화면 중앙
- 안내 토스트: 화면 상단 중앙

## 8. 상태 전이

- `idle` ↔ `walk` 또는 `run`
- `idle`/`walk`/`run` → 도구 행동 → `idle`
- 살아 있는 상태 → `hurt` → `idle`
- 살아 있는 상태 → `death`; `R` 입력 전까지 다른 행동 차단
- `R` 입력 → `idle`

행동 중에는 이동 입력으로 행동 프레임을 끊지 않는다. 행동 종료 후 마지막 방향의 대기 자세로 돌아간다.

## 9. 완료 조건

- `D`를 눌러 이동한 뒤 놓으면 오른쪽 대기 자세가 유지된다.
- `A`를 눌러 이동한 뒤 놓으면 왼쪽 대기 자세가 유지된다.
- `W`와 `S`도 각각 뒤와 앞 방향을 유지한다.
- 도끼, 곡괭이, 낚싯대를 장착하고 네 방향 각각에서 `E`/`Space`를 누르면 옆모습이 잘못 노출되지 않는다.
- 뒤 방향 행동의 도구는 캐릭터 몸 뒤에 표시된다.
- 검과 창 공격도 네 방향을 지원한다.
- 도구 슬롯의 아이템과 캐릭터가 들고 있는 도구가 일치한다.
- 인벤토리 첫 줄과 핫바가 항상 동일하다.
- 자동화 테스트와 실제 Pico2D 렌더 캡처가 모두 통과한다.

## 10. 주요 파일

- `main.py`: 입력, 캐릭터 상태, 애니메이션 및 UI 렌더링
- `game_model.py`: 아이템, 인벤토리, 핫바 및 장비 데이터
- `assets/Character Creation 32P/Character Creation 32P/Animations Adventurer.png`: 현재 캐릭터 아틀라스
- `tools/style_character_sheet.ps1`: 원본 캐릭터 시트에 모험가 의상 적용
- `tools/capture_game_preview.py`: 렌더 검수 캡처
- `tests/`: 상태·방향·인벤토리 자동화 테스트
