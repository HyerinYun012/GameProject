# CrowGame 프로토타입 PRD

- 문서 상태: 구현 기준선
- 최종 갱신: 2026-11-14
- 대상 빌드: 4개 맵 통합·월드 드롭·인벤토리·장비 검수 프로토타입

## 1. 목표

플레이어 캐릭터의 이동 및 행동 애니메이션과 15칸 인벤토리, 핫바, 도구, 방어구 장착 흐름을 유지하면서 네 개의 맵을 하나의 플레이 흐름으로 연결한다. 인벤토리 아이템은 월드에 버리고 다시 주울 수 있어야 한다.

현재 단계의 핵심은 다음과 같다.

1. 마지막 이동 방향이 캐릭터의 대기 방향으로 유지되어야 한다.
2. 도구 슬롯에 장착한 도구가 캐릭터에게 즉시 시각적으로 반영되어야 한다.
3. 앞, 뒤, 오른쪽, 왼쪽 네 방향에서 장착 도구의 행동이 올바른 방향으로 재생되어야 한다.
4. 인벤토리 첫 줄과 핫바가 동일한 데이터를 공유해야 한다.
5. 폐허 마을, 까마귀 숲, 늑대 숲, 곰 숲의 인접 맵을 양방향으로 이동할 수 있어야 한다.
6. 아이템을 슬롯 밖에 놓으면 인벤토리에서 제거되고 월드에 아이콘으로 표시되어야 한다.

## 2. 현재 범위

### 포함

- 남성 모험가 캐릭터
- 걷기와 달리기
- 네 방향 대기 자세 유지
- 피격과 쓰러짐
- 검·창 공격
- 도끼질, 채광질, 낚시
- 15칸 인벤토리
- 5칸 핫바
- 도구 및 방어구 장착
- 수집 아이템의 인벤토리 자동 추가 시험
- Tiled JSON 타일·오브젝트 레이어 직접 렌더링과 배경 PNG 폴백
- 카메라, 지형/오브젝트 충돌, 스폰, 맵 전환
- 맵별 월드 아이템 드롭과 재획득
- JSON `Resources` 및 `Events` 오브젝트 렌더링과 상호작용
- 곰 숲 엔딩 통로와 게임 종료

### 제외

- 낚시터 상호작용
- 전투 대상과 실제 피해 계산
- 저장 및 불러오기
- 제작, 상점, 퀘스트

`E`는 가까운 리소스와 이벤트에 상호작용하고, `Space`는 장착 도구 애니메이션을 직접 실행한다. 월드에 떨어진 아이템은 접근 시 자동 획득한다.

## 3. 조작

| 입력 | 동작 |
|---|---|
| `W` | 위로 이동, 키를 놓으면 뒤를 본 대기 자세 유지 |
| `S` | 아래로 이동, 키를 놓으면 앞을 본 대기 자세 유지 |
| `A` | 왼쪽 이동, 키를 놓으면 왼쪽을 본 대기 자세 유지 |
| `D` | 오른쪽 이동, 키를 놓으면 오른쪽을 본 대기 자세 유지 |
| `Shift + WASD` | 달리기 |
| `Tab` | 인벤토리 열기·닫기 |
| 마우스 왼쪽 드래그 | 인벤토리·핫바·장비 슬롯 간 아이템 이동 |
| 슬롯 밖으로 드래그 | 아이템 스택을 현재 맵에 버리고 아이콘 표시 |
| `E` | 가까운 리소스 채집 또는 이벤트 상호작용 |
| `Space` | 현재 도구 슬롯에 장착한 도구 사용 |
| `H` | 피격 애니메이션 검수 |
| `K` | 쓰러짐 애니메이션 검수 |
| `R` | 쓰러진 캐릭터 일으키기 |
| `Esc` | 게임 종료 |

## 4. 방향 및 애니메이션 규칙

### 방향 상태

- 방향은 `up`, `down`, `left`, `right` 네 가지다.
- 이동키를 누르면 해당 방향으로 갱신한다.
- 이동키를 놓아 `idle` 상태가 되어도 마지막 방향을 변경하지 않는다.
- 행동이 종료된 뒤에도 행동을 시작한 방향을 유지한다.
- 좌우 대기 프레임은 원본 아틀라스의 실제 얼굴 방향과 일치해야 한다.

### 이동 프레임

- 좌우 이동은 각 9프레임을 사용한다.
- 앞뒤 이동은 반대 방향 프레임이 섞이지 않도록 각 5프레임만 사용한다.
- 달리기는 걷기와 동일한 프레임을 더 높은 FPS로 재생한다.

### 도구 행동 방향표

| 도구 종류 | 앞 `down` | 뒤 `up` | 오른쪽 `right` | 왼쪽 `left` |
|---|---|---|---|---|
| 나무·돌 도끼 | 정면 몸동작 + 도끼 궤적 | 후면 몸동작 + 캐릭터 뒤 도끼 궤적 | 원본 우측 도끼질 | 우측 도끼질 좌우 반전 |
| 나무·돌 곡괭이 | 정면 몸동작 + 곡괭이 궤적 | 후면 몸동작 + 캐릭터 뒤 곡괭이 궤적 | 원본 우측 채광질 | 우측 채광질 좌우 반전 |
| 낚싯대 | 정면 몸동작 + 낚싯대 궤적 | 후면 몸동작 + 캐릭터 뒤 낚싯대 궤적 | 원본 우측 낚시 | 원본 좌측 낚시 |
| 나무·돌 검 | 원본 정면 공격 | 원본 후면 공격 | 원본 우측 공격 | 원본 좌측 공격 |
| 나무·돌 창 | 원본 정면 공격 | 원본 후면 공격 | 원본 우측 공격 | 원본 좌측 공격 |
| 횃불 | 방향별 장착 표시 | 방향별 장착 표시 | 방향별 장착 표시 | 방향별 장착 표시 |

원본 시트에 도끼·곡괭이·낚싯대의 앞뒤 전용 완성 프레임이 없으므로 앞뒤 행동은 방향에 맞는 정면·후면 몸 프레임과 장착 아이콘의 궤적을 합성한다. 뒤 방향에서는 도구를 캐릭터보다 먼저 그려 몸 뒤에 위치하도록 한다.

## 5. 캐릭터 외형

- 기본 외형은 남성 숲 모험가다.
- 올리브색 긴소매 튜닉, 가죽 벨트와 장갑, 짙은 바지와 부츠를 착용한다.
- 모든 상태에서 얼굴, 체형, 색상 및 픽셀 화풍을 통일한다.
- 대기, 걷기, 달리기, 피격, 쓰러짐 및 도구 행동에서 의상이 유지되어야 한다.

## 6. 인벤토리와 장비

### 인벤토리

- 5열 × 3행, 총 15칸이다.
- 시작 인벤토리에는 검, 창, 도끼, 곡괭이, 낚싯대, 횃불 계열 도구 10개만 배치한다.
- 방어구, 재료, 침구는 시작 인벤토리에서 제거하며 나머지 5칸은 빈 칸으로 둔다.
- 수집된 아이템은 기존 스택을 먼저 채우고, 남으면 앞쪽 빈 슬롯부터 들어간다.
- 빈 공간이 없으면 아이템을 잃지 않고 획득 실패를 표시한다.
- 데이터 모델은 아이템 추가, 슬롯 전체/부분 제거, 아이템 ID 기준 제거를 지원한다.

### 월드 드롭

- 인벤토리, 핫바, 도구, 방어구 아이템을 유효 슬롯 밖으로 드래그하면 해당 스택을 플레이어 주변 화면 거리 80~130픽셀의 통과 가능한 임의 위치로 옮긴다.
- 직접 던진 월드 드롭은 줌과 무관하게 76픽셀의 큰 아이콘으로 표시하고, 2개 이상일 때 수량도 함께 표시한다.
- 월드 드롭은 맵마다 별도로 유지되며 맵을 왕복해도 남아 있어야 한다.
- 플레이어가 월드 드롭의 화면 기준 115픽셀 이내로 접근하면 기존 스택 또는 빈 슬롯에 자동으로 추가한다.
- 플레이어가 직접 버린 아이템은 즉시 다시 획득되지 않는다. 투척 지점에서 30픽셀 이상 이동하면 획득이 활성화되므로 아이템 쪽으로 자연스럽게 접근해도 주울 수 있다.
- 채집 보상이 인벤토리 부족으로 월드에 남은 경우에는 별도의 이탈 과정 없이 접근 시 자동 획득한다.
- 공간 부족으로 일부만 들어가면 남은 수량은 월드에 유지한다.

### 핫바

- 화면 하단 중앙에 항상 표시한다.
- 인벤토리 0~4번 슬롯을 그대로 보여준다.
- 별도 복사본을 만들지 않으며 인벤토리 첫 줄과 항상 동기화한다.

### 도구 슬롯

- 화면 우측 하단에 항상 표시한다.
- 검, 창, 도끼, 곡괭이, 낚싯대, 횃불만 넣을 수 있다.
- 장착 직후 캐릭터 옆에 해당 도구를 표시한다.
- 도구를 빼거나 교체하면 캐릭터 표시와 행동도 즉시 갱신한다.

### 방어구 슬롯

- 도구 슬롯 옆에 항상 표시한다.
- 간이 갑옷만 넣을 수 있다.
- 현재 간이 갑옷 장착 시 방어력은 4 증가한다.

## 7. UI 배치

- 핫바: 화면 하단 중앙
- 도구 슬롯: 화면 우측 하단
- 방어구 슬롯: 도구 슬롯 오른쪽
- 인벤토리: `Tab`을 누른 동안 화면 중앙
- 안내 토스트: 화면 상단 중앙
- 현재 맵 이름: 화면 좌측 상단

## 8. 맵 구성과 전환

| 순서 | JSON | PNG 폴백 | 연결 |
|---|---|---|---|
| 1 | `ruined_town_demo.json` | `ruined_town_demo.png` | 시작 맵, 까마귀 숲과 왕복 |
| 2 | `crow_map.json` | `map_background.png` | 폐허 마을·늑대 숲과 왕복 |
| 3 | `wolf_map.json` | `wolf_background.png` | 까마귀 숲·곰 숲과 왕복 |
| 4 | `bear_map.json` | `bear_background.png` | 늑대 숲과 왕복, 엔딩 통로 보유 |

- JSON의 `spawn` 및 점 오브젝트 이름을 목적지 스폰으로 사용한다.
- `transitions` 레이어의 `target_map`, `target_spawn`, `end_game` 속성을 읽는다.
- `collision` 레이어의 사각형은 플레이어 발 위치의 충돌 판정에 사용한다.
- 폐허 마을은 `Walls`의 비어 있지 않은 타일을 충돌 지형으로 자동 변환한다.
- 폐허 마을의 자동차, 가구, 상자, 장벽, 펜스, 나무 등 고형 `Props`는 이미지 하단 발판 영역에 충돌을 적용한다. 피, 웅덩이, 잡초 같은 바닥 장식은 통과할 수 있다.
- 보이는 `tilelayer`의 GID, 레이어 순서, 가로·세로·대각선 반전 플래그를 읽어 TSX 타일 이미지를 직접 렌더링한다.
- 폐허 마을의 `Props`처럼 GID를 가진 일반 오브젝트도 JSON 좌표와 크기로 렌더링한다.
- `ruined_town_demo.json`의 타일셋은 `assets/ruined_town` 내부 경로만 사용하며 사용자 PC의 `Downloads` 경로에 의존하지 않는다.
- 렌더 가능한 타일 레이어가 없는 맵에만 표의 PNG를 폴백 배경으로 사용한다.
- 이미 방문한 맵도 JSON 수정 시간이 달라지면 다음 맵 진입 시 캐시를 갱신한다.
- Tiled의 좌상단 Y축 좌표를 Pico2D의 좌하단 Y축 좌표로 변환한다.
- 배경과 맵 오브젝트 좌표는 4배 렌더 스케일을 공유한다.
- 카메라 줌은 모든 맵에서 0.50배로 고정해 기존보다 넓은 월드 영역을 표시한다.
- 전환 직후 같은 통로로 되돌아가는 현상을 막기 위해 통로 영역을 벗어난 뒤 재진입해야 다시 전환한다.
- 곰 숲의 `end_game=true` 통로에 들어가면 종료 안내를 표시한 뒤 게임을 종료한다.

### 리소스와 이벤트 상호작용

- `Resources` 레이어의 오브젝트 좌표, 크기, `resource_type`, `hp`, `drop_item`, `drop_count`를 읽어 월드 이미지로 표시한다.
- 나무는 도끼 계열 도구가 `tool` 슬롯에 장착된 경우에만 피해를 받고, HP가 0이 되면 사라지면서 나무를 지급한다.
- 돌은 곡괭이 계열 도구가 `tool` 슬롯에 장착된 경우에만 피해를 받고, HP가 0이 되면 사라지면서 돌을 지급한다.
- 풀과 꽃은 도구 없이 `E` 한 번으로 수확하며 사라지고 섬유를 지급한다.
- 사과나무는 도구 없이 `E`로 사과 3개를 수확하며 사라지지 않는다. 사과 아이템은 `assets/apple.png`를 인벤토리 및 월드 아이콘으로 사용한다.
- 수확한 사과나무에는 완료 표시와 남은 재수확 시간을 표시하고 정확히 30초 뒤 다시 수확 가능하게 한다.
- `Events` 레이어의 이벤트는 `E`로 실행한다. `after_sprite`가 있는 이벤트는 완료 이미지로 바뀌고, 없는 일회성 이벤트는 사라진다.
- 발전기 이벤트는 `E`를 누를 때마다 켜짐/꺼짐 이미지와 상태를 전환한다.
- `required_tool=pickaxe` 이벤트는 곡괭이를 장착해야 실행할 수 있다.
- 획득 아이템이 인벤토리에 전부 들어가지 않으면 남은 수량은 이벤트/리소스 위치에 월드 드롭으로 남긴다.

## 9. 상태 전이

- `idle` ↔ `walk` 또는 `run`
- `idle`/`walk`/`run` → 도구 행동 → `idle`
- 살아 있는 상태 → `hurt` → `idle`
- 살아 있는 상태 → `death`; `R` 입력 전까지 다른 행동 차단
- `R` 입력 → `idle`

행동 중에는 이동 입력으로 행동 프레임을 끊지 않는다. 행동 종료 후 마지막 방향의 대기 자세로 돌아간다.

## 10. 완료 조건

- `D`를 눌러 이동한 뒤 놓으면 오른쪽 대기 자세가 유지된다.
- `A`를 눌러 이동한 뒤 놓으면 왼쪽 대기 자세가 유지된다.
- `W`와 `S`도 각각 뒤와 앞 방향을 유지한다.
- 도끼, 곡괭이, 낚싯대를 장착하고 네 방향 각각에서 `Space`를 누르면 옆모습이 잘못 노출되지 않는다.
- 뒤 방향 행동의 도구는 캐릭터 몸 뒤에 표시된다.
- 검과 창 공격도 네 방향을 지원한다.
- 도구 슬롯의 아이템과 캐릭터가 들고 있는 도구가 일치한다.
- 인벤토리 첫 줄과 핫바가 항상 동일하다.
- 자동화 테스트와 실제 Pico2D 렌더 캡처가 모두 통과한다.
- 첫 실행 시 폐허 마을 배경 위 지정 스폰에 캐릭터가 표시된다.
- 폐허 마을의 Ground, Walls, Props와 까마귀 숲의 모든 보이는 타일 레이어가 각 JSON의 최신 데이터와 일치한다.
- 폐허 마을 ↔ 까마귀 숲 ↔ 늑대 숲 ↔ 곰 숲을 양방향으로 이동할 수 있다.
- 각 맵에서 카메라와 충돌 판정이 배경 좌표에 맞게 동작한다.
- 폐허 마을에서 건물 벽과 고형 소품을 통과할 수 없고 도로 및 출구 통로는 이동 가능하다.
- 곰 숲 엔딩 통로에서 게임이 종료된다.
- 시작 인벤토리에는 도구만 있고 5칸은 비어 있다.
- 아이템을 슬롯 밖으로 드래그하면 플레이어 주변 임의 위치에 큰 월드 아이콘이 보이고, 범위를 벗어났다가 다시 접근하면 자동 획득할 수 있다.
- 직접 버린 아이템은 캐릭터가 범위를 벗어났다가 다시 접근하면 자동으로 인벤토리에 들어간다.
- 자동 획득 중 인벤토리가 가득 차면 들어가지 못한 수량은 월드에 그대로 남는다.
- JSON의 나무·돌·풀·꽃·과일나무와 이벤트 이미지가 배경 위 정확한 좌표에 표시된다.
- 나무/돌은 올바른 도구를 장착해야만 채집되고, 일반 리소스는 수확 완료 시 사라진다.
- 사과나무는 수확 후 남아 있으며 `apple.png` 사과 보상, 완료 표시와 30초 재수확 대기시간이 동작한다.
- 이벤트가 `E` 입력에 따라 완료 이미지로 바뀌거나 월드에서 사라진다.

## 11. 주요 파일

- `main.py`: 입력, 캐릭터 상태, 카메라, 월드 드롭, 애니메이션 및 UI 렌더링
- `game_model.py`: 아이템, 인벤토리, 핫바 및 장비 데이터
- `map_system.py`: 4개 맵의 JSON 로딩, 좌표 변환, 충돌, 스폰, 전환, 리소스 및 이벤트 데이터
- `assets/Character Creation 32P/Character Creation 32P/Animations Adventurer.png`: 현재 캐릭터 아틀라스
- `tools/style_character_sheet.ps1`: 원본 캐릭터 시트에 모험가 의상 적용
- `tools/capture_game_preview.py`: 렌더 검수 캡처
- `tests/`: 상태·방향·인벤토리 자동화 테스트
