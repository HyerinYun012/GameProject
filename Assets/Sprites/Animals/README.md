# Animal sprite sheets

`The Last Wile Human`의 8방향 쿼터뷰 동물 스프라이트입니다. 모든 PNG는 RGBA 투명 배경이며 한 프레임의 셀 크기는 `256 x 256 px`입니다.

## 공통 레이아웃

- 행 방향 순서: `S, SE, E, NE, N, NW, W, SW`
- 프레임 순서: 왼쪽에서 오른쪽
- 곰/늑대 피벗 권장값: `(128, 248)`
- 까마귀 피벗 권장값: `(128, 128)`

| 애니메이션 | 프레임/방향 | 반복 | 비고 |
| --- | ---: | --- | --- |
| idle | 4 | 예 | 대기 |
| walk | 6 | 예 | 곰/늑대 걷기, 까마귀 비행 이동 |
| attack | 6 | 아니오 | 곰/늑대만 포함 |
| hurt | 3 | 아니오 | 피격 반응 |
| death | 6 | 아니오 | 마지막 프레임에서 정지 |

각 동물 폴더의 `*.sprite.json` 파일에 파일명, FPS, 반복 여부와 피벗이 정리되어 있습니다.

이 스프라이트는 프로젝트 전용으로 이미지 생성 도구를 사용해 제작했으며, 외부 유료 에셋 파일은 포함하지 않았습니다.
